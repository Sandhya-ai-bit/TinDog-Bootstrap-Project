# 🐶 TinDog

A modern and responsive landing page for a fictional dog-dating app, built using HTML5, CSS3, and Bootstrap 5, featuring a clean layout, custom sections, and responsive grid design.

## 🌐 Live Demo
🔗 https://sandhya-ai-bit.github.io/TinDog/

## 🚀 Features
- Fully responsive design (mobile, tablet, desktop)
- Bootstrap grid system and utility classes
- Custom SVG icons (Apple, Google Play, checkmarks, etc.)
- "As Seen On" press logos section
- Pricing plan cards section
- Testimonial section
- Call-to-action buttons with hover effects

## 🛠️ Technologies Used
- HTML5
- CSS3
- Bootstrap 5

🧩 Challenges Faced

* Getting Bootstrap's grid system (row, col-*) to behave correctly across different breakpoints without content overlapping
* Using flex-lg-row-reverse to switch the image/text order between mobile and desktop views
* Aligning inline SVG icons properly within buttons while keeping them responsive
* Matching spacing and typography closely to the original design reference

📖 What I Practiced

* Bootstrap's responsive grid (row, col-*) and breakpoints
* Flexbox utility classes (d-flex, justify-content-*, align-items-*)
* Component styling (buttons, cards, navbar)
* Working with SVG icons inline in HTML
